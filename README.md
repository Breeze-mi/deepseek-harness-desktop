# DeepSeek Harness Desktop

面向 [DeepSeek Harness](https://www.npmjs.com/package/@deepseek-ai/dsh)（`DSH`）的 Windows 桌面封装。基于 Tauri v2 + Vue 3 + TypeScript。

> 技术栈：Tauri v2 + Vue 3 + TypeScript

## 功能

**首次启动自动完成**

- 检测 Node，版本不合格就下载便携版放进应用目录，**不动你系统里已有的**
- 镜像源加速（阿里云 → 清华 → 官方），下载后校验 SHA256，**校验和单独向官方取**，防的是镜像投毒而不只是传输损坏
- 全局安装 `dsh`，与你命令行里的是同一份
- 装好界面插件（鲸鱼娘、任务看板、皮肤中心），**装完自检**，装不上会明确报错而不是留个空界面
- 安装期间走镜像加速，但**不写入你的全局 npm 配置**

**日常使用**

|              |                                                              |
| ------------ | ------------------------------------------------------------ |
| 任务完成提醒 | 系统通知 + 任务栏闪烁 + 托盘图标闪烁，只在你没看着窗口时提醒 |
| 全局快捷键   | 默认 `Alt+Space` 唤起/收起，可改可关                         |
| 托盘常驻     | 关闭主窗口时三选：退出 / 最小化到托盘 / 取消                 |
| 热重启       | dsh 卡住时可单独重启服务，不用重启整个应用                   |
| 版本管理     | 设置页可查看并升级 dsh 与界面插件                            |

## 环境要求

Windows 10 / 11。Node.js ≥ 22.19 或 ≥ 24 —— 没有或版本不符时应用会自动下载便携版，所以不是硬性前置。

## 安装

从 [Releases](../../releases) 下载：

- **`-setup.exe`**（推荐）装到用户目录，不需要管理员
- `.msi` 装到 `Program Files`，需要管理员，适合批量部署

首次运行会弹 SmartScreen（本项目未购买代码签名证书），点「更多信息 → 仍要运行」。

## 开发

需要 [Rust](https://rustup.rs/) 与 pnpm。

```bash
pnpm install
pnpm tauri dev      # 首次会真的去装 dsh 和插件，可能要几分钟
pnpm tauri build    # 打 NSIS + MSI
```
